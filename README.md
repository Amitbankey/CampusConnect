
# CampusConnect

A student-centric campus mobility and local services platform.

## Project Modules

- mobile: Student and Driver mobile application
- admin: Admin dashboard
- server: Backend API and database
- docs: Project documentation

## Technology Stack

- Mobile: React Native with Expo
- Admin: React with Vite
- Backend: Node.js and Express
- Database: PostgreSQL
- ORM: Prisma
